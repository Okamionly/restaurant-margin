## Bug choisi

**Fichier** : `client/src/pages/Settings.tsx` — ligne 445  
**Catégorie** : Bug UX / donnée incorrecte  
**Sévérité** : Moyenne (affichage plan erroné à l'utilisateur)

### Avant
```ts
const [currentPlan] = useState<'pro' | 'business'>('pro');
```

### Après
```ts
const currentPlan = (user?.plan === 'business' ? 'business' : 'pro') as 'pro' | 'business';
```

### Raison
`currentPlan` était hardcodé à `'pro'` pour tous les utilisateurs. Le badge plan actif
dans la page Paramètres → Abonnement affichait toujours "PRO" quelle que soit la souscription
réelle. Or `user.plan` est déjà disponible via `useAuth()` (retourné par `/api/auth/me`).
Fix : dériver `currentPlan` depuis `user?.plan` sans état local.
