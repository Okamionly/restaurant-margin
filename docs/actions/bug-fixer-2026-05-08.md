## Bug choisi

**Fichier** : `api-lib/routes/ai.ts`  
**Catégorie** : Performance / Bug logique  
**Sévérité** : Moyenne — double requête DB à chaque appel IA

### Description
Trois routes IA appelaient `checkMonthlyQuota()` deux fois de suite, causant une double requête SQL sur la table `ai_usage` à chaque request :
- Route `/forecast` — lignes 1348 + 1350 (ex)
- Route `/optimize-recipe` — lignes 1548 + 1550 (ex)
- Route `/weekly-report` — lignes 1842 + 1848 (ex)

Résidu du commit `FIX 2026-04-28 (audit cohérence #9)` qui avait ajouté l'appel `checkMonthlyQuota` comme "fix d'uniformisation" sans retirer celui déjà présent.

### Avant (exemple /forecast)
```ts
if (await checkMonthlyQuota(req.restaurantId, res)) return;
// FIX 2026-04-28 (audit cohérence #9) : quota mensuel check uniforme.
if (await checkMonthlyQuota(req.restaurantId, res)) return;
```

### Après
```ts
if (await checkMonthlyQuota(req.restaurantId, res)) return;
```

### Impact
- **-6 requêtes DB** par cycle d'appel IA (3 routes × 2 requêtes → 1 chaque)
- Suppression du risque de double réponse HTTP si la première passe et la deuxième échoue (race condition entre deux checks consécutifs)
