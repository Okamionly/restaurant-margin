## Problème 2 — Tableau de sensibilité : aucune ligne surlignée si hausse ∉ {5, 10, 15, 20}

**Lignes** : 47, 95-97, 202  
**Symptôme** : La condition `isSelected = pct === hausse` ne peut jamais être vraie quand l'utilisateur choisit une valeur hors des 4 scénarios fixes (ex: hausse=7%, 12%, 25%). Le tableau n'avait aucun surlignage teal, rendant le lien entre les KPIs du haut et la table illisible.

### Avant
```ts
const SCENARIOS = [5, 10, 15, 20];
// ...
{SCENARIOS.map(pct => {
  const isSelected = pct === hausse;
```

### Après
```ts
const BASE_SCENARIOS = [5, 10, 15, 20];
// ...
const scenarios = BASE_SCENARIOS.includes(hausse)
  ? BASE_SCENARIOS
  : [...BASE_SCENARIOS, hausse].sort((a, b) => a - b);
// ...
{scenarios.map(pct => {
  const isSelected = pct === hausse; // toujours vrai pour au moins 1 ligne
```

### Impact
- Hausse standard (5/10/15/20%) → comportement inchangé
- Hausse custom (ex: 7%) → 5ème ligne insérée dynamiquement et surlignée en teal
- 5 lignes modifiées, 0 dépendance ajoutée
