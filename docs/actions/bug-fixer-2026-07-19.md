# Bug Fixer — 2026-07-19

## Bug fixé : Accents français manquants dans NegociationIA.tsx

**Source** : Inspection UX du code — aucun TODO/FIXME trouvé, build QA déjà corrigé, identification par grep des strings user-facing  
**Fichier** : `client/src/pages/NegociationIA.tsx`  
**Commit** : `fix(ui): corriger les accents manquants dans NegociationIA`

---

## Problème

La page Négociation IA (`/negociation-ia`) affichait ~30 strings françaises sans accents, visibles par tous les utilisateurs connectés. Cela donnait une impression de bug d'encodage ou de traduction ratée.

**Exemples de ce qui s'affichait :**
- Onglets : `"Opportunites"`, `"Economies"`
- Statuts pipeline : `"Identifie"`, `"Contacte"`, `"En negociation"`, `"Accepte"`, `"Refuse"`
- KPIs : `"ingredients surpayes"`, `"negociations actives"`, `"negociations reussies"`, `"Economies realisees"`, `"cette annee"`
- Messages vides : `"Aucune opportunite detectee"`, `"Aucune negociation en cours"`
- Scripts générés : `"regulierement"`, `"represente un ecart significatif"`, `"ouverts a la discussion"`, etc.
- Bouton : `"Copie !"` au lieu de `"Copié !"`

---

## Solution

Correction de 62 strings dans `NegociationIA.tsx` :

| Zone | Avant | Après |
|------|-------|-------|
| STATUS_CONFIG | `'Identifie'` | `'Identifié'` |
| STATUS_CONFIG | `'Contacte'` | `'Contacté'` |
| STATUS_CONFIG | `'En negociation'` | `'En négociation'` |
| STATUS_CONFIG | `'Accepte'` | `'Accepté'` |
| STATUS_CONFIG | `'Refuse'` | `'Refusé'` |
| Onglets | `'Opportunites'` | `'Opportunités'` |
| Onglets | `'Economies'` | `'Économies'` |
| Script email | `'regulierement'` | `'régulièrement'` |
| Script email | `'marche'` | `'marché'` |
| Script appel | `'J'espere'` | `'J'espère'` |
| Script appel | `'couts ingredients'` | `'coûts ingrédients'` |
| KPIs | `'cette annee'` | `'cette année'` |
| Bouton copy | `'Copie !'` | `'Copié !'` |
| … (50+ autres) | sans accents | avec accents corrects |
