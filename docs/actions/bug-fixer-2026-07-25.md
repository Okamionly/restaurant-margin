## Raison
Le composant AlertsBell est visible de tous les utilisateurs authentifiés dans la topbar. Sans i18n, un utilisateur anglophone voyait "Alertes prix", "Aucune alerte prix", "Voir details", "Ignorer" etc. en français — incohérent avec le reste de l'UI internationalisée.
