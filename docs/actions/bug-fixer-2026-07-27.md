## Bug identifié

**Type** : Bug UX / dark mode  
**Fichier** : `client/src/App.tsx`  
**Occurrences** : 96 lignes

### Description
96 fallbacks `<Suspense>` utilisaient `"min-h-screen bg-white flex items-center justify-center"` sans variante dark mode. En mode sombre, chaque navigation entre pages (lazy-loaded) provoquait un flash blanc pendant le chargement du chunk JS — visible notamment sur les 80+ pages blog/SEO/logiciel-marge.

### Avant
```tsx
fallback={<div className="min-h-screen bg-white flex items-center justify-center">
```

### Après
```tsx
fallback={<div className="min-h-screen bg-white dark:bg-black flex items-center justify-center">
```

## Impact
- Corrige le flash blanc en dark mode sur 96 routes (blog, fonctionnalités, logiciel-marge, alternatives, comparatifs, outils, pages légales)
- 8 routes avaient déjà le fix — non touchées
- Aucun changement de comportement en light mode
