## Bug détecté

**Type** : Chaînes hardcodées françaises bypassant le système i18n

**Fichier** : `client/src/pages/Ingredients.tsx` — lignes 2311, 2319, 2320

**Description** : Dans la modale de tracker de prix, 3 strings étaient hardcodées en français :
1. `'Sauvegarder'` / `'Supprimer'` — label du bouton selon la valeur d'alerte
2. `` `Prix actuel (${pricePerUnit} €) depasse le seuil !` `` — message quand prix au-dessus du seuil
3. `` `Prix sous le seuil (${threshold} €)` `` — message quand prix en dessous du seuil

**Impact** : Utilisateurs en EN/AR/ES/DE voyaient les labels en français dans la modale d'alerte de prix.

---

## Fix appliqué

### Locales (5 fichiers)

Ajout de 3 clés dans la section `ingredients` de chaque locale :

| Clé | FR | EN | AR | ES | DE |
|-----|----|----|----|----|-----|
| `alertSaveBtn` | Sauvegarder | Save | حفظ | Guardar | Speichern |
| `alertAbove` | Prix actuel ({price} €) dépasse le seuil ! | Current price ({price} €) exceeds threshold! | السعر الحالي ({price} €) يتجاوز الحد! | Precio actual ({price} €) supera el umbral! | Aktueller Preis ({price} €) überschreitet Schwellenwert! |
| `alertBelow` | Prix sous le seuil ({price} €) | Price below threshold ({price} €) | السعر دون الحد ({price} €) | Precio por debajo del umbral ({price} €) | Preis unter Schwellenwert ({price} €) |

### Composant

**Avant** :
```tsx
{parseFloat(alertInput) > 0 ? 'Sauvegarder' : 'Supprimer'}
// ...
? `Prix actuel (${trackerIngredient.pricePerUnit.toFixed(2)} €) depasse le seuil !`
: `Prix sous le seuil (${getAlertForIngredient(trackerIngredient.id)?.toFixed(2)} €)`
```

**Après** :
```tsx
{parseFloat(alertInput) > 0 ? t('ingredients.alertSaveBtn') : t('ingredients.deleteTooltip')}
// ...
? t('ingredients.alertAbove').replace('{price}', trackerIngredient.pricePerUnit.toFixed(2))
: t('ingredients.alertBelow').replace('{price}', (getAlertForIngredient(trackerIngredient.id) ?? 0).toFixed(2))
```

Note : `deleteTooltip` existait déjà dans les 5 langues, réutilisé pour éviter la duplication.
