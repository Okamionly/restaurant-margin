## Bugs fixés

### 1. `client/src/pages/OutreachMailer.tsx` — ligne ~458

**Problème** : bouton "Envoyer" utilisait `disabled:bg-[#94A3B8]` (slate-400), violation de la règle zero-slate. Aucun spinner lors de l'envoi.

**Avant** :
```tsx
import { Send, Mail, FileText, Plus, X, Check, AlertCircle, Sparkles } from 'lucide-react';
// ...
className="... disabled:bg-[#94A3B8] ..."
<Send className="w-4 h-4" />
{sending ? 'Envoi en cours...' : 'Envoyer...'}
```

**Après** :
```tsx
import { Send, Mail, FileText, Plus, X, Check, AlertCircle, Sparkles, Loader2 } from 'lucide-react';
// ...
className="... disabled:opacity-60 disabled:cursor-not-allowed ..."
{sending ? <Loader2 className="w-4 h-4 animate-spin" /> : <Send className="w-4 h-4" />}
{sending ? 'Envoi en cours...' : 'Envoyer...'}
```

**Raison** : `disabled:bg-[#94A3B8]` est une valeur slate interdite par le design system. `disabled:opacity-60` est cohérent avec le reste de l'app. Ajout d'un spinner Loader2 pour retour visuel pendant l'envoi.

### 2. `client/src/components/WeighModal.tsx` — ligne 172

**Problème** : bordure du display LCD de la balance utilisait `#334155` (slate-700) pour l'état inactif (poids = 0).

**Avant** :
```tsx
border: `2px solid ${netWeight > 0 && isStable ? '#10b981' : netWeight > 0 ? '#3b82f6' : '#334155'}`,
```

**Après** :
```tsx
border: `2px solid ${netWeight > 0 && isStable ? '#10b981' : netWeight > 0 ? '#3b82f6' : '#404040'}`,
```

**Raison** : `#334155` est slate-700, interdit. `#404040` est un gris neutre non-slate, visuellement équivalent sur fond sombre.
