## Bug fixé

### `client/src/components/blog/BlogArticleHero.tsx` — lignes 90 et 109

**Problème** : deux occurrences de `text-[#0F172A]` (slate-900) sans variante dark mode, violant la règle "zero slate" et "chaque élément doit avoir light ET dark mode" de CLAUDE.md.

**Avant** :
```tsx
// ligne 90
<span className="text-[#0F172A] font-medium truncate">{category}</span>
// ligne 109
<h1 className="text-3xl sm:text-4xl md:text-5xl lg:text-6xl font-black text-[#0F172A] leading-tight tracking-tight mb-6">
```

**Après** :
```tsx
// ligne 90
<span className="text-[#111111] dark:text-white font-medium truncate">{category}</span>
// ligne 109
<h1 className="text-3xl sm:text-4xl md:text-5xl lg:text-6xl font-black text-[#111111] dark:text-white leading-tight tracking-tight mb-6">
```

**Raison** : `#0F172A` est slate-900, interdit par le design system W&B. Remplacé par `#111111 dark:text-white`, le pattern standard pour le texte principal selon CLAUDE.md. Les articles blog (SEO public) s'affichaient en noir dur en dark mode, rendant le titre illisible sur fond sombre.
