## Bug fixé

### `client/src/components/AssistantWidget.tsx` — ligne 313

**Problème** : dans le renderer markdown maison du widget IA, la liste `<ul>` (puces non ordonnées) utilisait uniquement `marker:text-[#A3A3A3]` sans variante dark mode.  
En light mode, les puces s'affichaient en `#A3A3A3` (gris très clair) sur un fond `#F5F5F5` — contraste insuffisant, quasi-invisible.  
La liste `<ol>` voisine (même fichier, ligne 308) avait correctement `marker:text-[#737373] dark:marker:text-[#A3A3A3]`.

**Avant** :
```tsx
<ul key={key} className="list-disc pl-4 space-y-1 marker:text-[#A3A3A3]">
```

**Après** :
```tsx
<ul key={key} className="list-disc pl-4 space-y-1 marker:text-[#737373] dark:marker:text-[#A3A3A3]">
```

**Raison** : CLAUDE.md impose « chaque élément doit avoir light ET dark mode ». Le dark-only `#A3A3A3` était utilisé à tort en light mode où la couleur standard des textes secondaires est `#737373`.
