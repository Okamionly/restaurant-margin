## Fixes appliqués

### 1. `client/src/pages/AllergenMatrix.tsx` — ligne 252

**Problème** : `Loader2` et texte de chargement sans classe dark mode.

**Avant** :
```tsx
<Loader2 className="w-6 h-6 animate-spin text-[#9CA3AF]" />
<span className="ml-2 text-sm text-[#9CA3AF]">Chargement de la matrice allergenes...</span>
```

**Après** :
```tsx
<Loader2 className="w-6 h-6 animate-spin text-[#9CA3AF] dark:text-mono-500" />
<span className="ml-2 text-sm text-[#9CA3AF] dark:text-mono-500">Chargement de la matrice allergenes...</span>
```

**Raison** : En dark mode, le spinner et le texte restaient invisibles (même couleur que le fond).

---

### 2. `client/src/pages/FournisseurPromo.tsx` — ligne 270

**Problème** : Paragraphe de chargement sans aucune classe CSS → texte brut non stylisé.

**Avant** :
```tsx
<p>Chargement des promotions...</p>
```

**Après** :
```tsx
<p className="text-sm text-[#9CA3AF] dark:text-mono-500">Chargement des promotions...</p>
```

**Raison** : Le texte n'avait ni taille, ni couleur — incohérent avec le spinner Loader2 du parent.

---

### 3. `client/src/pages/Settings.tsx` — ligne 1728-1729

**Problème** : Bouton "Gérer mon abonnement" avec icône statique non conditionnelle + typo sans accent.

**Avant** :
```tsx
<ExternalLink className="w-4 h-4" />
{portalLoading ? 'Chargement...' : 'Gerer mon abonnement'}
```

**Après** :
```tsx
{portalLoading ? <RefreshCw className="w-4 h-4 animate-spin" /> : <ExternalLink className="w-4 h-4" />}
{portalLoading ? 'Chargement...' : 'Gérer mon abonnement'}
```

**Raison** : L'icône ne changeait pas pendant le chargement (mauvais feedback UX). Correction de "Gerer" → "Gérer" (accent manquant).
