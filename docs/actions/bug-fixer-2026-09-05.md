## Fix appliqué : i18n — 5 strings hardcodées dans `Analytics.tsx`

| Ligne | Avant | Après |
|-------|-------|-------|
| 258 | `'Erreur chargement rapport'` | `t('analytics.errorLoading')` |
| 586 | `'Rapport telecharge !'` | `t('analytics.reportDownloaded')` |

**`common.retry`** (fr + en) :
- fr : `Réessayer`
- en : `Retry`

**`analytics.errorLoading`** (5 langues) :
- fr : `Erreur de chargement du rapport`
