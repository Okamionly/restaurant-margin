## Fix appliqué : i18n — 6 strings hardcodées dans `SupplierRatingSystem` (Marketplace.tsx)

**Fichier** : `client/src/pages/Marketplace.tsx`

### Problème

Le composant `SupplierRatingSystem` (lignes ~842–1000) utilisait `useTranslation` dans le composant parent `Marketplace` mais **pas dans le sous-composant**. Résultat : 6 strings UI en dur en français, visibles par tous les utilisateurs y compris les anglophones.

### Strings corrigées

| Avant | Après |
|-------|-------|
| `'Evaluation des fournisseurs'` | `t('marketplace.ratingTitle')` |
| `'Notez vos fournisseurs sur 4 criteres...'` | `t('marketplace.ratingSubtitle')` |
| `'Recommande'` (badge) | `t('marketplace.ratingRecommended')` |
| `'Prix'` (label critère) | `t('marketplace.ratingPrice')` |
| `'Qualite'` (label critère) | `t('marketplace.ratingQuality')` |
| `'Livraison'` (label critère) | `t('marketplace.ratingDelivery')` |
| `'Communication'` (label critère) | `t('marketplace.ratingCommunication')` |
| `'Sauvegarder'` (bouton) | `t('common.save')` |
| `'Modifier'` (bouton) | `t('common.edit')` |

### Clés ajoutées aux locales

**`fr.json`** et **`en.json`** (section `marketplace`) :

| Clé | FR | EN |
|-----|----|----|
| `ratingTitle` | Évaluation des fournisseurs | Supplier ratings |
| `ratingSubtitle` | Notez vos fournisseurs sur 4 critères... | Rate your suppliers on 4 criteria... |
| `ratingRecommended` | Recommandé | Recommended |
| `ratingPrice` | Prix | Price |
| `ratingQuality` | Qualité | Quality |
| `ratingDelivery` | Livraison | Delivery |
| `ratingCommunication` | Communication | Communication |

`common.save` (`Enregistrer` / `Save`) et `common.edit` (`Modifier` / `Edit`) existaient déjà dans les deux locales.

### Raison

Le composant `SupplierRatingSystem` importait `useTranslation` via le fichier (import présent à la ligne 12) mais n'appelait pas le hook localement. 6 labels + 2 boutons interactifs étaient donc toujours affichés en français quelle que soit la langue choisie par l'utilisateur.
