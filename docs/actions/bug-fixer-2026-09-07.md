# Bug Fixer — 2026-09-07

## Bug fixé

**Fichier** : `client/tsconfig.json`

**Problème** : `import.meta.env` générait une erreur TypeScript `Property 'env' does not exist on type 'ImportMeta'` dans deux fichiers :
- `client/src/services/api.ts:4` — `const API_BASE = import.meta.env.VITE_API_URL || '/api';`
- `client/src/utils/errorTracker.ts:25` — `if (import.meta.env.DEV)`

**Cause** : Le `compilerOptions` de `client/tsconfig.json` ne déclarait pas `"types": ["vite/client"]`. Sans ce type, TypeScript ne connaît pas les extensions Vite sur `ImportMeta` (notamment `.env` et `.DEV`).

**Fix appliqué** :
```diff
// client/tsconfig.json
  "compilerOptions": {
    ...
-   "forceConsistentCasingInFileNames": true
+   "forceConsistentCasingInFileNames": true,
+   "types": ["vite/client"]
  }
```

**Impact** : Élimine les 2 erreurs TS réelles identifiées par le CTO. Améliore l'intellisense VSCode sur `import.meta.env`. Sans impact sur le build Vite (qui gérait déjà nativement).
