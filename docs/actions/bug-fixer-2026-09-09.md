# Bug Fixer — 2026-09-09

## Bug corrigé

**Fichier** : `client/tsconfig.json`

**Erreur signalée** (QA 2026-09-08) :
```
error TS2688: Cannot find type definition file for 'vite/client'.
  The file is in the program because:
    Entry point of type library 'vite/client' specified in compilerOptions
TSC exit code: 2
```

## Cause

La propriété `"types": ["vite/client"]` dans `compilerOptions` de `tsconfig.json` est invalide.
TypeScript attend dans ce tableau des **noms de packages top-level** (ex: `"node"`, `"jest"`), pas des sous-chemins de module comme `"vite/client"`.

Le fichier `client/src/vite-env.d.ts` fournit déjà correctement ces types via :
```ts
/// <reference types="vite/client" />
```

La directive triple-slash dans `vite-env.d.ts` est la méthode recommandée par Vite pour inclure les types client (`import.meta.env`, `import.meta.hot`, etc.).

## Fix

**Avant** (`client/tsconfig.json`) :
```json
"forceConsistentCasingInFileNames": true,
"types": ["vite/client"]
```

**Après** :
```json
"forceConsistentCasingInFileNames": true
```

Suppression de la clé `"types": ["vite/client"]` du `compilerOptions`. La résolution des types Vite est désormais assurée exclusivement par `vite-env.d.ts`.

## Impact

- Élimine l'erreur `TS2688` persistante reportée par QA
- Aucun impact fonctionnel (le build Vite n'utilisait pas cette option)
- Production toujours stable (15/15 pages OK)
