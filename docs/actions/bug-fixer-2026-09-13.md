## Bug détecté

**Type :** Messages d'erreur i18n manquants dans `RecipeDetail.tsx`  
**Sévérité :** Mineure — 6 messages d'erreur hardcodés en français non traduisibles en mode EN.

### Contexte

Le rapport QA du 2026-09-12 signalait une erreur TypeScript dans `BlogLogicielReservation.tsx` (`canonicalPath` → `path`) déjà corrigée par le commit `29a4aa0`. Aucun nouveau bug critique détecté. Grepping TODO/FIXME/HACK : résultat vide.

Scan complémentaire des strings hardcodées dans les pages → `RecipeDetail.tsx` utilise `useTranslation` mais 6 messages d'erreur dans les `catch` blocks étaient en dur en français, non couverts par les clés i18n.

### Fichiers concernés
