### Fix : 2 toasts hardcodés en français dans Recipes.tsx

**Fichier** : `client/src/pages/Recipes.tsx`

**Lignes concernées** : 2350, 2354 (avant fix)

**Avant** :
```ts
// ligne 2350
showToast(`Pack "${pack.name}" importe : ${created} recette(s) creee(s)`, 'success');
// ligne 2354
showToast(`Erreur lors de l'import du pack "${pack.name}"`, 'error');
```

**Après** :
```ts
// ligne 2350
showToast(t('recipes.packImportSuccess').replace('{name}', pack.name).replace('{count}', String(created)), 'success');
// ligne 2354
showToast(t('recipes.packImportError').replace('{name}', pack.name), 'error');
```

**Clés i18n ajoutées** :
- `client/src/locales/fr.json` : `recipes.packImportSuccess`, `recipes.packImportError`
- `client/src/locales/en.json` : `recipes.packImportSuccess`, `recipes.packImportError`

**Raison** : Ces toasts étaient les derniers messages hardcodés en français dans le flux d'import de packs de recettes, identifiés par grep lors de l'audit quotidien. L'app est multilingue (5 langues), tous les toasts doivent passer par le hook `t()`.
