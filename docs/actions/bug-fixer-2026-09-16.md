## Bug fixé : division par zéro dans le tableau récapitulatif de RoiEquipement

### Fichier
`client/src/pages/RoiEquipement.tsx` — ligne 227 (avant correction)

### Symptôme
La ligne "Amortissement mensuel" du tableau récapitulatif recalculait la valeur en inline :
```tsx
fmt(eq.prixAchat / (eq.dureeAmortissement * 12))
```
Si l'utilisateur saisit `0` dans le champ "Durée d'amortissement" (possible malgré `min={1}` — l'attribut empêche le stepper mais pas la saisie directe), le calcul produit `Infinity`. `fmt(Infinity)` affiche "∞ €", ce qui est incorrect et trompeur.

### Paradoxe
La fonction `calcRoi()` disposait déjà de la garde correcte :
```ts
const amortMensuel = dureeMois > 0 ? eq.prixAchat / dureeMois : 0;
```
Elle était utilisée dans `RoiCard` via `useMemo`, mais le composant parent `RoiEquipement` dupliquait la formule sans la garde.

### Fix

**Avant :**
```tsx
// RoiEquipement — ~ligne 129
const labelCls = ...
const inputCls = ...
```
```tsx
// ~ligne 227
['Amortissement mensuel', fmt(eq.prixAchat / (eq.dureeAmortissement * 12)), 'text-[#111111] dark:text-white'],
```

**Après :**
```tsx
const roiResult = calcRoi(eq);

const labelCls = ...
const inputCls = ...
```
```tsx
['Amortissement mensuel', fmt(roiResult.amortMensuel), 'text-[#111111] dark:text-white'],
```

### Résultat
- `dureeAmortissement = 0` → affiche "0 €" (amortMensuel protégé dans calcRoi) au lieu de "∞ €"
- Aucune duplication de logique : la garde existe dans un seul endroit (`calcRoi`)
