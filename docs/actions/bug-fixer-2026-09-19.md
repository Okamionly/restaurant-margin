# Bug Fixer — 2026-09-19

**Heure** : 11:00 (Paris)  
**Commit** : `885ce93`

## Bug corrigé

**Catégorie prerender incorrecte pour `/blog`** — `client/scripts/prerender.cjs`

### Symptôme

La page `/blog` (index du blog) recevait la catégorie `'landing'` lors du prérendu statique, car la condition existante vérifiait `route.path.startsWith('/blog/')` (avec slash terminal), ce qui ne matchait pas `/blog` sans slash.

Conséquence directe : le HTML statique prérendu pour `/blog` contenait le texte générique de la landing page ("RestauMargin — la plateforme tout-en-un…") au lieu d'un contenu décrivant l'index du blog. Le BreadcrumbList JSON-LD n'avait qu'un seul élément (Accueil) au lieu de deux (Accueil → Blog).

### Lien avec la régression QA (403 sur `/blog`)

Le 2026-09-18, la QA a détecté un 403 sur `/blog`. Ce 403 était probablement causé par le service worker PWA qui interceptait toutes les navigations (denylist ne couvrant que `/api/`) et servait l'`index.html` générique depuis son cache. Le commit `f9c8caa` (déployé le 2026-09-18 23:32) a étendu le denylist pour inclure `/blog`, ce qui a vraisemblablement résolu le 403. Le bug SEO corrigé aujourd'hui est une anomalie distincte mais liée (même route `/blog`).

### Correctif appliqué

Dans `client/scripts/prerender.cjs` :

1. **Catégorie** : ajout de `route.path === '/blog' ? 'blog-index' :` en tête du `ternaire` de détection.
2. **snippetText** `'blog-index'` : description des guides et articles du blog, sans le texte marketing de la landing.
3. **secondaryContent** `'blog-index'` : liste des 6 catégories d'articles du blog (calcul de marge, fiches techniques, HACCP, stocks, IA, menu engineering).
4. **relatedLinks** `'blog-index'` : 5 liens vers les articles blog clés (marge, coefficient multiplicateur, food cost, prime cost, fiche technique).
5. **BreadcrumbList JSON-LD** : pour `'blog-index'`, 2 niveaux seulement — Accueil → Blog — au lieu de 3. La condition `category !== 'landing' && category !== 'blog-index'` empêche l'ajout d'un 3ᵉ élément redondant.
6. **breadcrumbs** (visible) : `'Accueil > Blog'` pour `blog-index`, cohérent avec `article`.
7. **breadcrumbCategoryName** et **breadcrumbCategoryUrl** : `'Blog'` et `/blog` pour `blog-index`.

### Impact

- Le prochain build Vercel génèrera un `dist/blog/index.html` avec un contenu SEO pertinent pour un index de blog.
- Le BreadcrumbList JSON-LD sera valide (2 niveaux, pas de doublon d'URL).
- Aucun impact sur les sous-pages `/blog/*` (catégorie `'article'` inchangée).
