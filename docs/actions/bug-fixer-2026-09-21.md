## Bug choisi

**Fichier** : `client/src/pages/UserManagement.tsx`
**Ligne** : 137
**Type** : Toast non traduit (manqué dans le fix du 2026-09-20)

### Avant
```ts
showToast(data.error || 'Erreur', 'error');
```

### Après
```ts
showToast(data.error || t('Erreur lors de la suppression'), 'error');
```

### Raison
La string `'Erreur'` était une valeur brute sans `t()`. Elle n'existe pas dans `fr.json`/`en.json` — elle n'aurait jamais été traduite. La clé `'Erreur lors de la suppression'` existe déjà dans les deux fichiers de locale (`"Error deleting"` en EN). Ce fallback est utilisé quand la suppression d'un utilisateur échoue côté API et que `data.error` est vide.
