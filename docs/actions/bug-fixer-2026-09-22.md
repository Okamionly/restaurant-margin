## Bug sélectionné

**Fichier** : `client/tsconfig.json`
**Priorité** : Court terme (recommandé par CTO dans `docs/reports/cto-last.md`)

### Symptôme

```
Property 'env' does not exist on type 'ImportMeta'
```

Erreur TypeScript réelle (non liée à l'absence de node_modules) affectant :
- `client/src/services/api.ts` ligne 4 : `import.meta.env.VITE_API_URL`
- `client/src/utils/errorTracker.ts` ligne 25 : `import.meta.env.DEV`

### Cause

`client/tsconfig.json` ne déclarait pas `"types": ["vite/client"]` dans `compilerOptions`. Sans cette déclaration explicite, TypeScript ne reconnaît pas l'extension de `ImportMeta` fournie par Vite.

*Note : `client/src/vite-env.d.ts` existe déjà avec `/// <reference types="vite/client" />` mais la déclaration explicite dans tsconfig est la pratique recommandée et garantit la résolution dans tous les outils d'analyse.*

### Fix appliqué

**Avant :**
```json
{
  "compilerOptions": {
    ...
    "forceConsistentCasingInFileNames": true
  }
}
```

**Après :**
```json
{
  "compilerOptions": {
    ...
    "forceConsistentCasingInFileNames": true,
    "types": ["vite/client"]
  }
}
```
