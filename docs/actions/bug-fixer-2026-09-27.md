## Bug corrigé

**Tooltips contextuels codés en dur en français (sans accents)**

Les 11 messages d'aide contextuelle affichés à la première visite de chaque
page (dashboard, ingrédients, recettes, etc.) étaient codés en dur en français
approximatif (accents manquants, ex. « Creez », « deposez »). Un utilisateur
avec l'interface en anglais ou toute autre langue voyait les messages en
français incorrect.

| `client/src/components/ContextualTooltips.tsx` | 165 | 163 |

| `client/src/locales/en.json` | 2690 | 2701 |

### Avant (extrait)

```tsx
// Interface TooltipConfig avec champ `message: string`
const TOOLTIPS: TooltipConfig[] = [
  {
    route: '/dashboard',
    message: 'Voici votre tableau de bord. Les KPIs se remplissent automatiquement a mesure...',
    position: 'top',
  },
  // ...
];
// Rendu :
<p className="text-sm leading-relaxed">{tooltip.message}</p>
```

### Après

```tsx
// Interface TooltipConfig avec champ `messageKey: string`
const TOOLTIPS: TooltipConfig[] = [
  { route: '/dashboard', messageKey: 'tooltip.dashboard', position: 'top' },
  // ...
];
// Dans le composant :
const { t } = useTranslation();
// Rendu :
<p className="text-sm leading-relaxed">{t(tooltip.messageKey)}</p>
```

11 clés `tooltip.*` ajoutées dans `fr.json` (avec accents corrects) et
`en.json` (traductions anglaises complètes).
