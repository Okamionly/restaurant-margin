## Bug sélectionné

**Fichier** : `client/src/components/FloatingActionBubble.tsx`, ligne 55 (avant correction)

**Avant** :
```ts
if (!SpeechRecognition) { alert('Navigateur non supporte. Utilisez Chrome.'); return; }
```

**Après** :
```ts
if (!SpeechRecognition) { showToast('Navigateur non supporté. Utilisez Chrome.', 'error'); return; }
```

**Raison** : `alert()` natif bloque toute l'interface (modal bloquant, doit être fermé manuellement) et est incohérent avec le système de toast déjà en place (`useToast` / `ToastProvider`). Remplacement par `showToast` type `error` : non bloquant, stylisé, auto-dismiss à 3 s.

## Changements complémentaires

- Import de `useToast` depuis `../hooks/useToast` ajouté en tête de fichier
- Initialisation `const { showToast } = useToast()` dans le corps du composant
