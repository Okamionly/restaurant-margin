## Bug corrigé

**Fichier :** `client/src/App.tsx`  
**Ligne avant correction :** 644 (après ajout du hook, 646)

### Avant
```tsx
import { ToastProvider } from './hooks/useToast';
// ...
function AppLayout() {
  const { user, logout } = useAuth();
  const { selectedRestaurant } = useRestaurant();
  // ...
  onClick={() => alert('Cette fonctionnalité sera disponible prochainement')}
```

### Après
```tsx
import { ToastProvider, useToast } from './hooks/useToast';
// ...
function AppLayout() {
  const { user, logout } = useAuth();
  const { selectedRestaurant } = useRestaurant();
  const { showToast } = useToast();
  // ...
  onClick={() => showToast('Cette fonctionnalité sera disponible prochainement', 'info')}
```

### Raison
`alert()` est une API navigateur bloquante et non stylée. Elle gèle l'UI jusqu'à la confirmation de l'utilisateur et brise l'expérience visuelle. Ce pattern avait déjà été corrigé dans `AdminDashboard` (commit `e6e6e76`). La sidebar `AppLayout` contenait le dernier `alert()` restant.
