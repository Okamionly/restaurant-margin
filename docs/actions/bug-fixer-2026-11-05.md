## Bug corrigé

**Type :** Clé de traduction mal placée — bouton « Réessayer » affiché en français pour les utilisateurs arabes, espagnols, allemands.

**Fichiers modifiés :**
- `client/src/locales/ar.json`
- `client/src/locales/es.json`
- `client/src/locales/de.json`

### Cause

Le composant `Analytics.tsx` utilise `t('common.retry')` pour le bouton de rechargement affiché en cas d'erreur. La clé `common.retry` était absente des dictionnaires `ar`, `es`, `de`. Le hook `useTranslation` tombait donc sur le fallback français : les utilisateurs dans ces langues voyaient « Réessayer » au lieu de la traduction dans leur langue.

Les traductions correctes existaient déjà dans ces fichiers, mais mal placées sous `analytics.retry` (section incorrecte).

### Avant

```json
// ar.json, es.json, de.json
{
  "analytics": {
    "retry": "إعادة المحاولة"  // ar — clé orpheline, jamais utilisée
  }
  // "common" section absente
}
```

### Après

```json
// ar.json
{
  "common": { "retry": "إعادة المحاولة" },
  "analytics": { "retry": "إعادة المحاولة" }
}

// es.json
{
  "common": { "retry": "Reintentar" },
  "analytics": { "retry": "Reintentar" }
}

// de.json
{
  "common": { "retry": "Erneut versuchen" },
  "analytics": { "retry": "Erneut versuchen" }
}
```
