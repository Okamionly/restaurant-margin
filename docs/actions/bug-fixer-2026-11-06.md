## Bug corrigé

**Type :** 19 clés `common.*` manquantes dans ar/es/de — boutons universels affichés en français pour les utilisateurs non-FR.

**Fichiers modifiés :**
- `client/src/locales/ar.json`
- `client/src/locales/es.json`
- `client/src/locales/de.json`

### Cause

La section `common` de `fr.json` contient 20 clés utilisées partout dans l'app
(boutons Ajouter, Annuler, Enregistrer, Supprimer, Modifier, Rechercher, etc.).
Dans `ar.json`, `es.json` et `de.json`, cette section n'existait qu'avec la clé
`retry` (ajoutée le 2026-11-05). Les 19 autres clés étaient absentes : le hook
`useTranslation` tombait donc sur le fallback français, affichant du texte FR aux
utilisateurs arabes, espagnols et allemands sur tous ces éléments d'interface.

La clé `retry` doublée (présente en fin de fichier dans la section orpheline
`"common": { "retry": "..." }`) a été fusionnée dans la nouvelle section complète,
éliminant le doublon JSON.

### Avant

```json
// ar.json, es.json, de.json
{
  // ... section "common" absente ou réduite à {"retry": "..."}
}
```

### Après

```json

{
  "common": {
    "add": "أضف",
```
