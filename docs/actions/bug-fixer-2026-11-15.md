# Bug Fixer — 2026-11-15

## Source identifiée

Rapport CTO du 2026-11-14 : « deux corrections i18n en 48 h suggèrent un pattern systémique — les toasts sont ajoutés en français sans passer par `t()` ».

## Bug corrigé

**Fichier** : `client/src/App.tsx`, lignes 683–685 (avant correction)  
**Composant** : `AppLayout` → `renderNavItem` (items `disabled`)

### Avant
```tsx
title={collapsed ? item.label : 'Cette fonctionnalité sera disponible prochainement'}
onClick={() => showToast('Cette fonctionnalité sera disponible prochainement', 'info')}
```

### Après
```tsx
title={collapsed ? item.label : t('common.comingSoon')}
onClick={() => showToast(t('common.comingSoon'), 'info')}
```
