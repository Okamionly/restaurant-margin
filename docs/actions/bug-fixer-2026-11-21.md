## Bug choisi

**Fichier** : `client/src/components/NotificationCenter.tsx`, ligne 825  
**Symptôme 1** : `window.location.href = '/settings'` dans le footer du panneau de notifications provoquait un **rechargement complet de page** au lieu d'une navigation SPA interne — toute l'application se réinitialisait (état perdu, flash blanc, rechargement réseau) pour ce qui devrait être une simple transition de route.  
**Symptôme 2** : Le label « Preferences » (anglais hardcodé) et « Tout marquer comme lu » (français hardcodé) n'utilisaient pas le hook `useTranslation`, cassant la cohérence i18n du composant.

---

## Correction

### `client/src/components/NotificationCenter.tsx`

**Avant** :
```tsx
onClick={() => { setOpen(false); window.location.href = '/settings'; }}
...
Preferences
...
Tout marquer comme lu
```

**Après** :
```tsx
// imports ajoutés
import { useNavigate } from 'react-router-dom';
import { useTranslation } from '../hooks/useTranslation';

// dans le composant
const navigate = useNavigate();
const { t } = useTranslation();

// footer
onClick={() => { setOpen(false); navigate('/settings'); }}
...
{t('notifications.preferences')}
...
{t('notifications.markAllRead')}
```
