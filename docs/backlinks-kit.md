## 6. Notes et garde-fous SEO

- **Qualite > quantite** : eviter les fermes de liens et annuaires spammes (validation automatique = signal de risque). Tous les annuaires listes ici ont une validation manuelle ou une vraie audience.
- **Ancres variees** : ne pas sur-optimiser. Alterner "RestauMargin", "restaumargin.fr", "logiciel de gestion de marge restaurant", "le logiciel de food cost de RestauMargin". Trop d'ancres exactes "marge restaurant" = sur-optimisation penalisable.
- **Rythme naturel** : etaler les soumissions (ce que font les 3 vagues). Une explosion de 50 liens en 24h sur un domaine neuf est suspecte.
- **NAP coherent** (Name, Address, Phone) sur tous les annuaires locaux : exactement le meme nom, la meme adresse Montpellier, le meme telephone, pour le SEO local.
- **dofollow vs nofollow** : un profil sain melange les deux. Les nofollow (Product Hunt, Hacker News, Reddit) restent utiles (trafic, notoriete, liens secondaires).
- **Reverifier les DA** avant une grosse campagne : les chiffres de ce doc datent du 2026-06-02 et evoluent.
