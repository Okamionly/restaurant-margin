## Dette Technique TOP 3
1. **api/index.ts monolithique** : 6 443 LOC dans un seul fichier — risque de maintenance croissant, devrait être éclaté en modules par domaine (auth, recipes, ingredients, ai, billing)
2. **Response time 853ms** : latence API élevée (>800ms), probablement due à la cold start Supabase ou à des requêtes Prisma non optimisées (manque d'index ou N+1)
3. **0 nouveaux utilisateurs 24h** : pas de problème technique direct mais indicateur d'acquisition à surveiller — vérifier que les pages SEO sont bien indexées et que les funnels d'inscription fonctionnent

## Refacto Prioritaire
1. **Découper api/index.ts** : extraire les routes en fichiers séparés par domaine dans `api/routes/` (déjà commencé pour auth, ai, mercuriale — continuer pour recipes, ingredients, margins)
2. **Optimiser les requêtes Prisma** : ajouter des index sur les colonnes filtrées fréquemment (user_id, created_at) et auditer les requêtes N+1 avec Prisma query logging
3. **Monitoring response time** : mettre en place un tracking p95/p99 pour détecter les dégradations avant qu'elles impactent les utilisateurs
