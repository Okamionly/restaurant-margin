## Note Critique — Erreurs TypeScript

Les 101 063 erreurs TypeScript reportées sont un **artefact de l'environnement remote** : le dossier `client/node_modules/` n'est pas installé dans la session CI/cloud. En l'absence de `@types/react`, `react-router-dom`, `lucide-react`, etc., tsc produit des erreurs en cascade sur chaque fichier.

**Erreurs réelles identifiées (hors cascade)** :
- `client/src/services/api.ts:4` — `Property 'env' does not exist on type 'ImportMeta'` (manque `vite/client` dans tsconfig)
- `client/src/utils/errorTracker.ts:25` — même cause

Ces 2 erreurs sont connues et sans impact sur le build Vite (le plugin Vite gère `import.meta.env` nativement).

**Le site build et tourne correctement en production.** Aucune alerte envoyée.

## Dette Technique TOP 3

1. **api/index.ts trop volumineuse (7 302 LOC)** — fichier monolithique qui devrait être splittée en routes modulaires. Risque de maintenabilité élevé, merge conflicts fréquents si plusieurs agents travaillent simultanément.
2. **Erreurs `import.meta.env` dans tsconfig** — ajouter `"types": ["vite/client"]` dans `client/tsconfig.json` pour éliminer les 2 erreurs TS réelles et améliorer l'intellisense.
3. **0 nouveaux utilisateurs / 0 leads en 24h** — indicateur business critique ; la dette technique la plus coûteuse est l'absence de traction.

## Refacto Prioritaire

1. **Splitter `api/index.ts`** en modules distincts (`routes/ingredients.ts`, `routes/recipes.ts`, etc.) — objectif < 500 LOC par fichier.
2. **Ajouter `"vite/client"` dans tsconfig** — correction triviale (1 ligne), élimine les erreurs TS réelles.
3. **WeighStation.tsx** contient du JSX en dehors d'un contexte React valide (lignes 2806+) — à auditer lors du prochain sprint.
