## Erreurs TypeScript

- **Comptage brut CI** : 102 919 erreurs
- **Cause racine** : `node_modules` incomplet dans l'environnement d'exécution automatisé — `npm install` non exécuté → `@types/react` absent → cascade TS7026 sur tous les JSX
- **Vrais bugs identifiés** :
  - `src/pages/WeighStation.tsx` : ~800+ erreurs implicites `any` (TS7006) → paramètres sans type dans des callbacks
  - `src/services/api.ts` (l.4) + `src/utils/errorTracker.ts` (l.25) : `Property 'env' does not exist on type 'ImportMeta'` → manque `vite/client` dans les types
  - 257 fichiers affectés au total par le manque de `@types/react`

## Dette technique TOP 3

1. **`api/index.ts` monolithique — 7 302 lignes** : fichier unique qui concentre toute la logique backend. Risque de conflits, difficulté de lecture, maintenance lourde. Refactorisation en modules par domaine urgente.
2. **`WeighStation.tsx` non typé** : callbacks implicitement `any` dans un fichier de 2 800+ lignes. Risque de bugs silencieux en production.
3. **`ImportMeta.env` non déclaré** : `src/services/api.ts` et `errorTracker.ts` utilisent `import.meta.env` sans `vite/client` dans les types tsconfig. Fix trivial mais bloque la vérification TS propre.

## Refacto prioritaire

1. **Court terme (1j)** : Ajouter `"types": ["vite/client"]` dans `tsconfig.json` → élimine les 2 erreurs `ImportMeta.env` réelles
2. **Moyen terme (1 semaine)** : Typer les callbacks de `WeighStation.tsx` (TS7006) — fichier à splitter en sous-composants
3. **Long terme (sprint)** : Éclater `api/index.ts` en modules : `routes/`, `controllers/`, `services/` — la structure `api/routes/` existe déjà mais est sous-utilisée
