## Dette Technique TOP 3

1. **api/index.ts monolithique (7 817 lignes, +495 en 24h)** — le fichier
   continue de grossir quotidiennement. Sans éclatement en modules
   (`api/routes/<domaine>.ts`), chaque agent ajoute des centaines de lignes
   sans revue globale. C'est le risque principal d'instabilité à moyen terme.

2. **37 commits en 24h générés par des agents** — cadence record. Les
   fonctionnalités de prospection et de recette du jour ont toutes été
   livrées en une seule journée. Le risque : logique dupliquée entre les
   nouveaux endpoints agents et les routes existantes (auth, mercuriale, ai).
   Un grep de surface sur les fonctions similaires s'impose.

3. **Temps de réponse API : 1 380 ms** — proche du seuil critique (1,5 s).
   Hier non mesuré. Il faut investiguer : cold start Render, requête Prisma
   lente, ou overhead middleware. Un appel de référence sur `/api/health`
   (sans charge DB) devrait répondre < 300 ms.

## Refacto Prioritaire

**Mesurer puis corriger le temps de réponse API (1 380 ms)**

Étapes :
1. Tester `/api/health` sans le paramètre `?deep=1` pour isoler cold start vs DB.
2. Si c'est la DB : chercher les requêtes Prisma sans index sur les tables à fort volume.
3. Si c'est le cold start Render : envisager un cron ping toutes les 5 min pour maintenir l'instance chaude.

Cette latence impacte directement le taux de conversion sur l'essai gratuit.
