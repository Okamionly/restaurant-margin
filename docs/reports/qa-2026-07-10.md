## Build TypeScript — ❌ FAIL

**1 erreur TypeScript détectée :**

```
src/pages/BlogOuvrirTerrasseRestaurant.tsx(22,9): error TS2322:
Type '{ title: string; description: string; canonicalUrl: string; }'
is not assignable to type 'IntrinsicAttributes & SEOHeadProps'.
Property 'canonicalUrl' does not exist on type 'IntrinsicAttributes & SEOHeadProps'.
```

**Cause** : Le composant `<SEOHead>` ne supporte pas la prop `canonicalUrl`, mais `BlogOuvrirTerrasseRestaurant.tsx` l'utilise. Soit la prop a été supprimée de `SEOHeadProps`, soit elle n'a jamais été ajoutée.

**Correction suggérée** : Ajouter `canonicalUrl?: string` dans l'interface `SEOHeadProps`.
