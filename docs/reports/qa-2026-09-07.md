## Analyse

Le pattern 403 sur des pages spécifiques suggère un problème au niveau du CDN/proxy (Cloudflare, reverse proxy) ou d'un déploiement partiel. L'API backend répond correctement (200 health, 401 login), ce qui indique que le backend fonctionne. Le problème est côté frontend/routing/CDN.

**Hypothèses prioritaires :**
1. Règle Cloudflare bloquant certaines routes (WAF ou règle de redirection)
2. Déploiement frontend incomplet — certaines routes non générées
3. Problème de configuration du serveur web (nginx/caddy) pour le SPA routing

## Actions recommandées
