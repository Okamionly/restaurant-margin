## Action réalisée

Sortie de **Login** (et de ses dépendances i18n) du chunk `index` critique que **toutes** les pages publiques/SEO téléchargent avant le first paint.

### Diagnostic
- `client/src/App.tsx` importait `Login` **eagerly** → bundlé dans le chunk `index` (chargé sur chaque page landing/blog/pricing/outils), alors que Login ne s'affiche que sur `/login`.
- Login tirait avec lui le hook **`useTranslation` + la locale `fr` bundlée (~99 kB)** et un composant **`PaperFoldBackground` WebGL**.
- **Aucune page SEO n'importe `useTranslation`** (vérifié : 0 référence dans `Landing`, `BlogCalcMarge`, `BlogCoefficient`, `Pricing`, `FoodCostCalculator`, `NicheLanding`, `BlogFoodCost`). Ces pages téléchargeaient donc ~99 kB de machinerie i18n + locale **jamais utilisée**.
- `client/src/main.tsx` faisait un **prefetch idle du Dashboard** (chunk auth-gated) inconditionnel → visiteurs anonymes et crawlers téléchargeaient du code authentifié sur les pages SEO.

### Changements
- `App.tsx` : `Login` → `lazyRetry(() => import('./pages/Login'))` + route `/login` enveloppée dans `<Suspense>` (même pattern que les 40+ autres routes publiques du fichier).
- `main.tsx` : prefetch Dashboard **gate sur `localStorage.getItem('token')`** → skip pour les visiteurs anonymes / crawlers.
