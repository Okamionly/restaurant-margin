### ⚠️ Piège évité (vérif live) — `fetchPriority`
Initialement ajouté `fetchPriority="high"` sur les 2 héros. **`tsc -b` passait** (`@types/react` 18.3.12 type la prop), **mais le runtime `react-dom` 18.3.1 ne la reconnaît pas** (support natif seulement en React 19) → **warning console à chaque render** (`React does not recognize the fetchPriority prop… spell it lowercase`). Détecté en lisant la console du dev-server, pas par le build. `fetchpriority` minuscule fixerait le runtime mais **casserait `tsc -b`** (Vercel). → **prop retirée** : gain marginal sur un héro déjà `eager`, pas au prix d'un warning sur chaque page. Les autres hints (universellement supportés) sont conservés. *(Leçon type : un build TS vert ne prouve pas un runtime propre — les types précèdent le runtime.)*
