# SEO Daily — 2026-10-17 (samedi, optimisation technique)

## Verdict

**Une requête bloquant le rendu a été retirée des ~130 pages publiques.** Le CSS global
commençait par un `@import` Google Fonts (JetBrains Mono). Avant d'afficher quoi que ce soit,
le navigateur devait donc charger `index.css`, puis ouvrir une connexion vers
`fonts.googleapis.com`, une origine froide sans preconnect. Or cette police ne sert que sur
la page d'accueil.

## Mesure en production (avant)

| Page | TTFB | HTML | Cache Vercel |
|---|---|---|---|
| `/` | 0,21 s | 17,6 Ko | HIT |
| `/blog/calcul-marge-restaurant` | 0,56 s | 146 Ko | HIT |
| `/pricing` | 0,71 s | 17,6 Ko | HIT |

Ressources critiques communes (Brotli / brut) : `index.js` 46,6 / 186 Ko,
`vendor-react` 56 / 166 Ko, `vendor-icons` 25 / 134 Ko, `index.css` **40 / 306 Ko**.

- Le CSS servi commençait par `@import"https://fonts.googleapis.com/css2?family=JetBrains+Mono…"`.
  C'est une chaîne bloquante HTML → CSS → CSS tiers.
- Coût mesuré de la requête tierce depuis ce poste en fibre : 113 à 274 ms (DNS + TLS + réponse).
  Sur mobile 4G (RTT environ 150 ms), il faut quatre allers-retours, soit environ 0,6 s
  (estimation non mesurée).
- Usage réel de JetBrains Mono : uniquement les styles inline de `Landing.tsx`. Les classes
  `font-mono` des articles utilisent la pile système de Tailwind, pas JetBrains.

Fausse piste écartée : des pixels Facebook et LinkedIn avec des ID fictifs apparaissaient
dans le HTML. Ils sont dans des commentaires, donc jamais chargés. Rien à faire.

## Ce qui a été fait

- `client/src/index.css` : `@import` retiré, avec un commentaire qui en donne la raison.
- `client/src/pages/Landing.tsx` : la feuille JetBrains Mono et un preconnect
  `fonts.gstatic.com` sont ajoutés via `Helmet`, sur la seule page d'accueil. Ils sont insérés
  par JavaScript, donc ne bloquent pas le rendu, et `display=swap` est conservé.
- Build local de la chaîne Vercel complète : `vite build` OK, SSR 108/108, prerender 132 pages,
  108 avec corps complet. Le CSS buildé ne contient plus `fonts.googleapis`, aucune page HTML
  ne charge la feuille, et seul le chunk `Landing-*.js` la référence.

Effet attendu : FCP et LCP plus courts sur toutes les pages hors accueil. Cela compense en
partie les +250 ms de FCP payés le 03/10 pour le corps SSR complet. Sur l'accueil, la police
mono arrive un peu plus tard (swap depuis SF Mono / ui-monospace). C'est un texte de petite
taille, le risque de CLS est négligeable.

**Non vérifié dans un navigateur** : le serveur de prévisualisation a été refusé pendant
ce run. Vérification faite sur les fichiers buildés, puis en production via curl (ci-dessous).
